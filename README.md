# Badoota Cloud Kitchen — Website

Premium website for **Badoota Cloud Kitchen** (San Jose, California). Authentic Karnataka/Bengaluru cuisine featuring traditional Donne Biryani, complete menu with online ordering integration, and custom programs (BBC Club, Licensing).

See the planning docs:
- `BADOOTA_CLOUD_KITCHEN_BUILD_PROMPT.md` — the master build specification
- Reference website: https://www.badoota.biz/

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Features

- **10+ Pages:** Home, Menu, About, Contact, BBC Club, Licensing, Delivery, Order Online, Cart
- **Complete Menu:** Full Badoota menu with categories, pricing (USD), dietary filters
- **Ordering Integration:** DoorDash, Uber Eats, Pickup ordering
- **Membership Program:** BBC Club with 20% discount showcase
- **Mobile-First:** Optimized for San Jose customers ordering on mobile
- **US Market:** USD pricing, US address formats, local business hours

## Stack

Next.js 14 (App Router) + TypeScript + Tailwind CSS + Zustand state management

## Content

All content, menu items, and business information extracted from the official Badoota website (https://www.badoota.biz/)
